# Lux Ticker 1.3.0

October 23, 2026. Built-in @LuxWire X feed alerts (no Wade handoff). Still `asInvoker`. Install with `LuxTicker-Setup.exe`.

- Lux Wire post alerts are on. While the app is running it polls the @LuxWire timeline on X every 3 minutes (2, 3, or 5 in Settings).
- The first poll marks posts already on the timeline as seen and does not toast. Later polls toast new posts. If the app was offline, the next poll catches up and keeps the newest 10.
- Public posts use an app bearer saved in Settings (`%APPDATA%\LuxTicker\x-auth.json`) or the `LUXWIRE_X_BEARER` environment variable. The token is not built into the app.

- Tap a toast to open `https://x.com/LuxWire/status/{id}`. Turning alerts off stops polling.

# Lux Ticker 1.0.1

Personal Windows build. No installer. The manifest stays `asInvoker` (no administrator password).

- Orange Lux Wire LW icon on the exe, window, taskbar, and tray.
- @LuxWire Windows toast alerts for every post, public and subscriber. This build is treated as subscribed. There is no paywall and no charge.
- Right-click **@LuxWire posts** to turn alerts on or off. The toggle is on until you save it off.
- **Simulate Lux Wire post** always shows a sample toast that opens https://x.com/LuxWire.
- Ingest is a local file, `%APPDATA%\LuxTicker\lux-wire\posts.jsonl`. Append a JSON line (`url`, `subscriber_only`, `posted_at`, optional `slot_type`, `text_preview`, optional `id`) or a bare post URL. Duplicate urls and ids are skipped. Lines already in the file the first time the app sees it are marked seen and do not toast. No FCM and no server.
- Tap a toast to open that post’s https://x.com/... URL. The ticker bar, prices, and app bar are unchanged.
